# 0G — qué usar y para qué

Docs hub: https://docs.0g.ai/  
Builder hub: https://build.0g.ai/

## Respuesta corta: ¿qué necesitamos de 0G?

Para HumanSplit, **no necesitás todo 0G el día 1**. Usá capas según la fase:

| Fase | Componente 0G | Para qué |
| --- | --- | --- |
| **1.5** | **0G Storage** | Guardar recibos del split (JSON con txs, montos, rule version) |
| **2** | **0G Chain + Agentic ID (ERC-7857)** | Tokenizar el agente / autorizar callers |
| **2** | **ERC-8004** | Hacer el agente discoverable en el ecosistema |
| **Opcional** | **0G Compute** | Inference del LLM sin OpenAI centralizado |
| **Opcional** | **0G DA** | Disponibilidad de datos en transfers Agentic ID |

La plata del split sigue yendo por **Base + Coinbase AgentKit**. 0G no reemplaza eso en el MVP.

## 0G Storage (recomendado después del primer split)

**Para qué:** cada vez que el agente reparte, subís un recibo:

```json
{
  "type": "humansplit-receipt",
  "timestamp": "2026-08-03T00:00:00Z",
  "humanBackedAgent": "0xAgent...",
  "rule": { "savings": 70, "spend": 20, "partner": 10 },
  "total": "100",
  "asset": "USDC",
  "chain": "base-sepolia",
  "txs": ["0xabc...", "0xdef...", "0x123..."]
}
```

**SDK / starter:**

- Docs SDK: https://docs.0g.ai/developer-hub/building-on-0g/storage/sdk
- TS starter kit: https://github.com/0gfoundation/0g-storage-ts-starter-kit
- Paquete típico: `@0gfoundation/0g-storage-ts-sdk` / `@0gfoundation/0g-ts-sdk` (ver README del starter)

**Posibilidades:**

| Opción | Descripción |
| --- | --- |
| Recibo público | Cualquiera con el root hash lo lee |
| Recibo cifrado | Solo el dueño / socio con la key |
| Solo hash onchain | Guardás el root hash en un evento o Agentic ID metadata |

## Agentic ID (ERC-7857) — fase 2

**Para qué:** convertir tu HumanSplit agent en un activo con inteligencia/config transferible.

Docs:

- Overview: https://docs.0g.ai/developer-hub/building-on-0g/agentic-id/overview
- Builder: https://build.0g.ai/agentic-id
- Examples: https://github.com/0gfoundation/agenticID-examples

Contrato demo testnet (examples beginner): `0x2700F6A3e505402C9daB154C5c6ab9cAEC98EF1F`

**Capacidades útiles para nosotros:**

| Función | Uso en HumanSplit |
| --- | --- |
| `mint` | Registrar el agente + hash de su rule/prompt |
| `authorizeUsage` | Dejar que otro address use tu agente sin transferirte ownership |
| `iTransferFrom` | Vender/transferir el agente con re-encryption |
| Marketplace example | Fase avanzada: listar el agente |

## ERC-8004 — discoverability

Si querés que otros agentes/herramientas te encuentren:

- Docs: https://docs.0g.ai/developer-hub/building-on-0g/agentic-id/erc8004
- Explorer ecosistema: https://8004scan.io

Agentic ID puede llevar registro ERC-8004. World AgentBook y ERC-8004 son capas distintas:

| Capa | Pregunta que responde |
| --- | --- |
| World AgentBook | ¿Hay un humano único detrás de esta wallet? |
| ERC-8004 | ¿Quién es este agente, dónde está, qué reputación tiene? |
| ERC-7857 | ¿Quién es dueño de la inteligencia/config del agente? |

## 0G Compute — opcional

## Resumen práctico

**Para hacerlo “correr en 0G” en el sentido útil para esta idea:**

1. Wallet + faucet Galileo.
2. Integrar **Storage** para receipts.
3. (Luego) clonar `agenticID-examples` y mintear tu agente.
4. (Luego) registrar ERC-8004 si querés discovery.

Las transacciones de dinero del producto siguen en **Base** vía Coinbase AgentKit, salvo que pivotees a un diseño 100% 0G-native (posible, pero peor liquidez/USDC DX hoy).
