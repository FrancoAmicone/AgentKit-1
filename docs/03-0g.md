# Resumen — 0G

**Links:** [Docs](https://docs.0g.ai/) · [Testnet](https://docs.0g.ai/developer-hub/testnet/testnet-overview) · [Agentic ID](https://docs.0g.ai/developer-hub/building-on-0g/agentic-id/overview) · [Builder Agentic ID](https://build.0g.ai/agentic-id)

## En una frase

Infraestructura para **AI + blockchain**: chain EVM, storage, compute e identidad de agentes (Agentic ID).

## Piezas principales

| Pieza | Qué es | Para qué sirve |
| --- | --- | --- |
| **0G Chain** | Red EVM (testnet Galileo / mainnet) | Contratos, gas barato, ops de agentes |
| **0G Storage** | Storage descentralizado | Memoria, recibos, datasets, metadata |
| **0G Compute** | Inference / AI compute | Correr modelos sin depender solo de OpenAI |
| **Agentic ID (ERC-7857)** | NFT de “inteligencia” del agente | Ownership, transfer con re-encryption, `authorizeUsage` |
| **ERC-8004** | Identity / reputation registries | Que el agente sea discoverable en el ecosistema |
| **0G DA** | Data availability | Disponibilidad en transfers verificables |

## Agentic ID — idea clave

Un NFT normal no lleva la “inteligencia” del agente. ERC-7857 permite:

- Guardar metadata/inteligencia cifrada (pesos, prompts, config).
- Transferir ownership **con** esa data (re-encryption + prueba TEE/ZKP).
- Autorizar uso sin transferir (`authorizeUsage`).

Examples oficiales: https://github.com/0gfoundation/agenticID-examples

## Qué te brinda (posibilidades)

1. **Solo Storage** — audit trail / memoria del agente.
2. **Storage + Chain** — guardar y referenciar onchain (hashes).
3. **Agentic ID** — el agente como activo transferible/alquilable.
4. **Compute** — inference en la red 0G.
5. **ERC-8004** — aparecer en explorers tipo 8004scan.

## Qué no es (por sí solo)

- No te da “humano verificado” (eso es World).
- No es el DX más simple para USDC/DeFi en Base (ahí suele ganar Coinbase/Base).
- No estás obligado a usarlo si tu idea solo necesita una wallet + transfers.
